# JPKI Local Signer

On-device PDF signing and verification with Japan's My Number Card (マイナンバーカード) — no servers, no closed SDKs, no network access.

- **Source code / Repository**: <https://github.com/nunnun/jpki-local-signer>
- **Privacy Policy / プライバシーポリシー**: [privacy](./privacy/)

マイナンバーカードで PDF に端末内完結の電子署名を行う iOS / macOS アプリです。詳細はリポジトリの README をご覧ください。
